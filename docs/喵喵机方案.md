- 每次切入主页都会重建，统计值始终最新。

## 四、页面

### 4.1 学习页

单词卡一次展开全部信息：

```
[<]  新词 / 待复习 Lv2 / Lv3 · 7 天后复习
abandon                     ← 30px 拉丁
UK /əˈbændən/  US /əˈbændən/  ← 12px（含 IPA）
v. 放弃；抛弃                 ← 21px 中文
He abandoned his car in the snow.
他把车丢弃在雪地里。
[ 没记住 ]  [ 模糊 ]  [ 记住了 ]   ← 红/橙/绿
```

- 顶部状态由复习调度决定（见第六节）。
- 每次评级 → 更新调度状态 → 落盘 → 自动选下一词。

### 4.2 闯关页

- **解锁条件**：本 Unit 全部词学习次数 ≥1；未解锁显示「已学 n/20 + 先学完本单元全部单词」。
- **规模**：每 Unit **20 词**，每关 **10 题**，**3 心**。
- **题型**：中→英四选一（4 选项洗牌），点击即时高亮（对绿/错红），700ms 自动切题（`lv_timer`，带防连点标志）。
- **错词当场重测**：本局答错的词入队（去重、上限 64），10 题答完自动进入重测阶段，标题切换为「错词重测 r/R」，重测完才结算。
- **高权重出题**：优先从"已学且错≥3次"的词中抽题，无此类词才退回任一已学词。
- **结算页**：按正确率给 ★（≥90% 三星 / ≥70% 两星 / ≥50% 一星）+ 答对 N/M + 「再闯一次 / 回主页」。

### 4.3 词库页

- **按 Unit 分页**（每页 20 词，标题「词库 3/376」，带上一页/下一页、循环翻页）。
- 每行：英文单词（拉丁 16px）+ 状态 + 计数「未学 / 学习中 / 已掌握 / 错词，学 n 错 m」。
- 设计说明：全量 7508 词不能一次性建控件（会创建 2 万多个 LVGL 对象撑爆内存），故按 Unit 分页。

### 4.4 设置页

| 行 | 右侧显示 | 行为 |
|---|---|---|
| 学习词汇 | CET-4 | 提示"当前仅 CET-4" |
| 主题 | 纸色/夜幕/掌机 | 点击循环切换，即时生效 + 落盘 |
| 无线网络 | 已连接/未连接 | WiFi 扫描列表 + 密码输入页 + 发起连接 |
| 每日目标 | 10 词/天 | 5→10→…→25 循环 + 落盘 |
| 复习提醒 | 开/关 | 开关 + 落盘 |

## 五、学习 ⇄ 闯关联动（核心闭环）

```
学习页(到期/逾期优先 → 错词重学 → 新词)
        │ 本 Unit 全部词学习次数 ≥1
        ▼
Unit 闯关解锁(10 题 · 3 心 · 中→英四选一)
        │ 答错 → 当场重测；结算后错词进复习队列并降级
        ▼
错词回流：学习页优先复习 → 答对清错 → 重新闯关
```

## 六、复习调度

每词独立调度，字段 `lv`(等级 0~5) / `due`(到期日) / `streak`(连续答对) / `rep`(复习次数)。

**分级间隔**：Lv0~5 对应 **1 / 2 / 4 / 7 / 15 / 30 天**。

| 评级 | 行为 |
|---|---|
| 没记住 | `err++`、等级归 0、进错词本、明天再来 |
| 模糊 | 等级降一级、明天再来 |
| 记住了 | `streak++`，**连续 2 次答对才升级**；销错；按新等级排下次到期 |

**选词优先级**（`next_word`）：最早到期（含逾期）→ 错词重学（`lv<3`）→ 新词 → 轮转。

**到期预警**：主页统计条「今日到期 / 已逾期 / 已学」；学习页顶部显示当前词状态。

## 七、本地存储

路径 `/data/mmj/`（断电不丢）：

**`words.json`** —— 进度主库，格式为合法 JSON，**扁平数组按词库顺序**：

```json
{"v":2,"n":7508,"w":[c0,e0,lv0,due0,rep0,st0, c1,e1,...]}
```

- 每词 6 个字段：`c` 学习次数 / `e` 错误次数 / `lv` 复习等级 / `due` 到期日(epoch 天数) / `rep` 复习次数 / `st` 连续答对。
- 读写**全程流式**（逐字符扫描），不依赖大缓冲，7508 词也不撑栈。
- **版本校验**：读到头部不是 `"v":2` 直接作废重来，避免旧格式被按位错读。

**`settings.json`** —— `{"theme":0,"daily":10,"remind":0}`，开机先 `settings_load()` 再 `theme_apply()`。

## 八、词库与字库

### 8.1 词库（7508 词 CET-4）

- 词库数据基于开源数据集 **english-vocabulary**（MIT License, Copyright (c) KyleBing）的 CET-4 词表。
- 清洗：`tools/gen_words.py` —— 取首条释义（词性+中文）、首条例句（英中对照）、英式+美式音标。
- 覆盖率：释义 100%、音标 99%、例句 98%。
- 产物：`app/hello_app/mmj_words.{h,c}`（约 1.34MB 源码），`MMJ_NWORD` 为**编译期常量**（用于数组维度）。
- 更新方式：`python3 tools/gen_words.py [词数上限]`，随后必须重跑字库脚本。

### 8.2 字库（多档精简）

- 由 `tools/gen_board_fonts.js` 生成：从**模拟器页面 + 板端 C 源码**自动提取实际用到的字符 → `lv_font_conv` 生成为 **LVGL bin** → 板端 `lv_binfont_create()` 运行时加载。
- 源字体：阿里巴巴普惠体。
- 5 档：**12 / 16 / 16b(ExtraBold) / 21 / 28 px**，bpp4，合计约 **2.08MB**，覆盖 **3158 个字符**（含 IPA 音标与中文释义用字），另有 IPA 音标专用字体与 GB2312 常用汉字库。
- 新增文案或词库后**必须重跑**，否则新字显示豆腐块。
- 字体生成脚本在生成后会自动清理板级 ETC romfs 缓存，保证新字库一定进入固件。

## 九、系统功能

- **WiFi 联网**：设置页扫描热点（wapi）、密码输入、发起连接；主页实时显示连接状态。
- **自动对时**：联网后后台任务直连 NTP 服务器（UDP 123）校时，失败时自动降级用 HTTP 响应头 Date 校时；时区为东八区。
- **开机自启**：系统启动脚本拉起应用，上电即进入学习界面。

### 9.1 板端 Web 管理（:8080）

板子内置 HTTP 管理服务，电脑接入同一 WiFi 后浏览器访问 `http://<板子IP>:8080`：

- **AI 模型配置**：MiMo API Key / Base URL / 模型名（保存于板子 `/data/mmj/ai.json`），支持一键测试连通性
- **学习数据**：已学 / 今日到期 / 已逾期 / 已掌握 实时统计，支持远程清空进度
- 管理页面来自固件 `/etc/web/admin.html`（romfs 只读）；设置页展示板子实际管理地址

### 9.2 AI 挑战（大模型出题）

入口在闯关页右上角。流程：

```
收集已学单词(随机 5 个) → 组 Prompt → 调 MiMo(chat/completions)
  → 解析返回的 JSON 题组 → 逐题: AI 气泡例句挖空 → 四选一 → AI 中文讲解 → 下一题 → 结算
```

- 题目类型：英文例句挖空（`___`），干扰项来自所给单词或形近变形
- 答题后气泡式反馈：答对/答错 + 单词、词性释义 + AI 一句话讲解
- 出题在后台任务执行（不阻塞 UI），请求失败可重试；未配置 Key 时提示去网页端配置
- MiMo 调用参数：`temperature=0.7`，`max_tokens=1600`，只输出 JSON 数组

## 十、构建与烧录

```bash
# 在 openvela 工作区根目录（本仓的上一级）
./build.sh vendor/allwinnertech/boards/r528/r528s3-dshanpi/configs/nsh/ -j8
```

用全志烧录工具（PhoenixSuit / LiveSuit）烧写 `.img` 到 SPI NAND，串口 115200 观察日志。

**构建护栏**：openvela 的 `build.sh` 在应用编译失败时仍会继续 pack，产出"构建成功但代码没进固件"的假镜像。`tools/build_eye.sh` 已加拦截：编译日志命中 `error:` 即中止 pack 并打印错误行。
